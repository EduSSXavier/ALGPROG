Consumindo APIs com Python

Na primeira parte você segue um passo a passo com a DogApi. Na segunda, resolve desafios com a API ViaCEP, sem receber o código pronto. Use o Google Colab: uma célula por passo.

Marque cada etapa ao concluir. Seu progresso fica salvo neste navegador.

Parte 1: DogApi, passo a passo

Cerca de 30 minutos. A DogApi (dogapi.dog) é pública e não pede cadastro nem chave.

1. Veja a API no navegador

Antes de programar, abra no navegador do seu celular ou computador:

https://dogapi.dog/api/v2/facts?limit=1

Esse é o “pedido” que seu programa Python vai repetir.

Verifique: você viu um texto em formato JSON com a chave data.

2. Faça sua primeira requisição

No Colab, rode:

import requests

resp = requests.get("https://dogapi.dog/api/v2/facts", params={"limit": 1}, timeout=10)
print(resp.status_code)
print(resp.json())
Verifique: o status impresso é 200 e o JSON tem a chave data.

3. Extraia o fato curioso

O JSON vira um dicionário Python. Explore o que há dentro de attributes:

dados = resp.json()
atributos = dados["data"][0]["attributes"]
print(atributos)

Descubra qual chave guarda o texto do fato e imprima somente ele.

Verifique: aparece apenas uma frase sobre cães, sem chaves nem colchetes.

4. Liste raças

resp = requests.get("https://dogapi.dog/api/v2/breeds", timeout=10)
racas = resp.json()["data"]
for raca in racas:
    print(raca["attributes"]["name"])

A API entrega os resultados em páginas, por isso você recebe só uma parte da lista.

Verifique: aparece uma lista de nomes de raças, um por linha.

5. Busque os detalhes de uma raça

Cada raça tem um id. Use o da primeira para montar uma nova URL:

id_raca = racas[0]["id"]
url = f"https://dogapi.dog/api/v2/breeds/{id_raca}"
detalhe = requests.get(url, timeout=10).json()
print(detalhe["data"]["attributes"])

Agora imprima uma frase formatada, por exemplo “Raça: NOME. Descrição: TEXTO”, usando as chaves que você encontrou.

Verifique: a frase mostra o nome e a descrição da mesma raça.

6. Trate um erro

Peça uma raça que não existe e observe a resposta:

resp = requests.get("https://dogapi.dog/api/v2/breeds/id-que-nao-existe", timeout=10)
print(resp.status_code)

Agora crie a função buscar_raca(id_raca), que devolve o dicionário da raça quando o status é 200 e None nos outros casos. Teste com um id válido e com um inválido.

Verifique: com o id inválido o programa não quebra e retorna None.

Parte 2: Desafios com a ViaCEP

Cerca de 20 minutos. A ViaCEP consulta endereços pelo CEP, também sem chave. O formato da URL é:

https://viacep.com.br/ws/CEP/json/

Agora o código é seu. Abra as dicas apenas se travar.

Desafio 1: consulte um CEP

Peça um CEP ao usuário com input(), consulte a API e mostre logradouro, bairro, cidade e estado.

Dica

Monte a URL com um f-string. Imprima o JSON inteiro primeiro para descobrir os nomes das chaves.

Verifique: um CEP real devolve o endereço completo.

Desafio 2: proteja o programa de CEPs inválidos

Teste um CEP com formato errado (por exemplo 123) e um que não existe (por exemplo 00000000). Observe o status e o corpo de cada resposta, e faça o programa mostrar uma mensagem clara em cada caso.

Dica

Um dos casos devolve status diferente de 200. O outro devolve 200, mas com uma chave erro no JSON. Trate os dois.

Verifique: nenhum CEP inválido faz o Python mostrar um erro vermelho (traceback).

Desafio 3: crie a função consultar_cep

Transforme sua solução em consultar_cep(cep). Ela deve aceitar “40020-000” e “40020000”, rejeitar o que não tiver 8 dígitos, usar timeout e devolver um dicionário ou None.

Dica

Para limpar o CEP, mantenha só os dígitos: "".join(c for c in cep if c.isdigit()). Capture também requests.exceptions.RequestException para falhas de rede.

Verifique: a mesma função funciona com hífen, sem hífen e com entradas inválidas.

Desafio bônus: descubra o CEP pelo endereço

A ViaCEP também faz a busca inversa, com o formato https://viacep.com.br/ws/UF/Cidade/Logradouro/json/. Consulte uma rua da sua cidade e imprima o CEP de cada resultado.

Dica

Nesse caso a resposta é uma lista de dicionários, não um dicionário só. O logradouro precisa ter ao menos 3 caracteres.

Verifique: aparece uma lista de CEPs da rua escolhida.
