Execução no Desktop

Pré-requisitos

Antes de executar um programa Python em seu computador, você precisa:

  • Instalar o interpretador Python (versão 3.6 ou superior)
  • Ter um editor de texto ou IDE (como VS Code, PyCharm, ou mesmo o IDLE que vem com o Python)
  • Ter conhecimento básico de sintaxe Python

Instalação do Python

Recomendamos baixar o Python do site oficial: AQUI

Durante a instalação, certifique-se de marcar a opção "Add Python to PATH" para facilitar a execução do Python via terminal.


Verificando a Instalação

Após a instalação, abra o terminal (Prompt de Comando no Windows ou Terminal no macOS/Linux) e digite:


python --version

Se a versão do Python for exibida, a instalação foi bem-sucedida.


Executando um Programa Python

1. Crie um arquivo chamado meu_programa.py com o seguinte conteúdo:


print("Olá, mundo!")

2. Salve o arquivo e abra o terminal na pasta onde ele está localizado.

3. Execute o programa digitando:


python meu_programa.py

Você verá a saída: Olá, mundo!

Execução Online via Browser

Se você não deseja instalar o Python em seu computador, pode usar ambientes online para escrever e executar código Python diretamente no navegador. Há diversas opções disponíveis. Aqui estão três exemplos:


Usando o site Programiz

O Programiz também oferece um ambiente online para executar código Python.


Para usar o Programiz:

  1. Acesse https://www.programiz.com/python-programming/online-compiler/
  2. Digite seu código no editor e clique em "Run" para executá-lo.

Usando o site Replit

O Replit é uma plataforma online que permite escrever e executar código em várias linguagens, incluindo Python, diretamente no navegador.


Para usar o Replit:

  1. Acesse https://replit.com/
  2. Clique em "Start coding" e selecione Python como linguagem.
  3. Digite seu código no editor e clique em "Run" para executá-lo.

Usando o Google Colab

O Google Colab é um ambiente de desenvolvimento baseado na nuvem que permite escrever e executar código em várias linguagens, incluindo Python, diretamente no navegador.


Para usar o Google Colab:

  1. Acesse https://colab.research.google.com/ ou entre em seu Google Drive.
  2. Clique em "New Notebook" para criar um novo notebook.
  3. Digite seu código em uma célula e pressione Shift + Enter para executá-lo.

Resumo

Esses ambientes online são ideais para testar rapidamente trechos de código, aprender Python sem instalar nada, ou quando você está em um computador que não permite instalações.

Escolha o ambiente que melhor se adapta às suas necessidades e comece a programar em Python!
